API reference

Starting and stopping MATLAB

FSDABridge.start_engine — Function
start_engine(; fsda_root = nothing, routine = nothing)

Start a MATLAB session with FSDA and return a handle to it, for use with call(handle, name, ...), eval_expr(handle, expr), diagnostics and stop_engine(handle).

This session is separate from the one the routine functions start automatically: stop_engine() does not stop it, and call(name, ...) does not use it.

Keywords

  • fsda_root: FSDA's install folder, needed only if FSDA is not installed as a MATLAB Add-On.
  • routine: an FSDA function name to look up at start; if MATLAB cannot find it, the session is closed and an error is raised.

On start, a notice is printed if a newer FSDA release is available.

source
FSDABridge.stop_engine — Function
stop_engine()

Shut down the MATLAB session that the routine functions, call(name, ...) and eval_expr(expr) start automatically. If that session is not running, it only prints a message.

To shut down a session started with start_engine, pass its handle: stop_engine(handle).

Calling FSDA and MATLAB directly

FSDABridge.call — Function
call(handle, name, args...; kwargs...)

Same as call(name, ...), but runs in the session handle returned by start_engine. Arguments, keywords and return values are as documented there.

source
call(name, args...; nargout = 1, echo_output = false, kwargs...)

Call the FSDA or MATLAB function name, starting the MATLAB session on first use. Positional arguments are passed in order; keyword arguments become MATLAB name-value pairs. Pass a response y as an n x 1 matrix (y[:, 1:1], not y[:, 1]) when a routine expects a column: a Julia vector reaches MATLAB as a row.

Keywords

  • nargout: how many outputs to request. With more than one, the outputs come back as a vector; with nargout = 0, nothing is returned.
  • echo_output: if true, MATLAB's console output is printed.

Examples

out = call("FSR", y, X; plots = 0, msg = 0)
call("rng", 1234; nargout = 0)

Structs come back as Dict{String,Any}, numeric arrays as Julia arrays. To use a session started with start_engine, pass its handle first: call(handle, name, ...).

source
FSDABridge.eval_expr — Function
eval_expr(handle, expr; nargout = 1)

Same as eval_expr(expr), but runs in the session handle returned by start_engine.

source
eval_expr(expr; nargout = 1)

Evaluate the MATLAB expression expr and return its result, starting the MATLAB session on first use. With the default nargout = 1, a MATLAB table comes back as a Dict. Useful when call is not enough.

Examples

Y = eval_expr("table2array(getfield(load('geyser2.mat'),'geyser2'))")

To use a session started with start_engine, pass its handle first: eval_expr(handle, expr).

Figures

FSDABridge.render_figures — Function
render_figures()

Update open MATLAB figures and process pending callbacks (using MATLAB's drawnow), so that plots appear while the script keeps running.

A session started with start_engine takes its handle: render_figures(handle).

source
FSDABridge.wait_for_figures — Function
wait_for_figures()

Draw any open MATLAB figures, then wait until the user has closed all of them. Returns immediately if no figures are open. Use it at the end of a script that plots, so the figures stay on screen until you close them.

A session started with start_engine takes its handle: wait_for_figures(handle).

source

Diagnostics

FSDABridge.diagnostics — Function
diagnostics(handle) -> NamedTuple

Report the versions in use for the session handle returned by start_engine: Julia, PythonCall, the Python interpreter and its version, MATLAB, and matlabengine. Useful when reporting a problem.
